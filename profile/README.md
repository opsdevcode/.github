### How we think about delivery

<table>
  <tr>
    <td width="33%" valign="top">
      <strong>One product</strong><br>
      Customers experience a product, not a queue of specialties. Delivery should match that.
    </td>
    <td width="33%" valign="top">
      <strong>Capability, not org chart</strong><br>
      Consume what the engineering system can do. The org that fulfills it is an implementation detail.
    </td>
    <td width="33%" valign="top">
      <strong>Guardrails in the path</strong><br>
      Policy, provenance, and golden paths live in the system — not as a ticket after the fact.
    </td>
  </tr>
</table>
