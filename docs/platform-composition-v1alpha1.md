# Platform composition v1alpha1

Mint names intent. SpecMint federates product capability manifests
(`opsdevcode.capability-manifest/v1alpha1`). Authority stays with Repave,
Overpass, Toll, and Dispatch. Relay is internal transport.

JSON adapters only. No product source imports into SpecMint. Fake-local
object storage and fake providers. Live cloud mutation is out of scope.

See `opsdevcode/specmint-platform` ADR 016.
